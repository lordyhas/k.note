# Security Policy

## Supported versions

Only the [latest release](https://github.com/lordyhas/k.note/releases/latest) receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub instead: go to the
[Security tab](https://github.com/lordyhas/k.note/security) and click
**Report a vulnerability**. Include the KNOTE version, the platform (Android or web), and the
steps to reproduce the issue.

You should get a first answer within a week. Once the issue is confirmed, a fix is
published in a new release and the advisory is made public.

How the app protects user data (Firestore rules, App Check, API keys) is described in
[docs/security.md](docs/security.md).
